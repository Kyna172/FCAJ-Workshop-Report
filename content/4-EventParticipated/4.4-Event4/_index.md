### Event Objectives

* Gain in-depth knowledge and practical insights into Cloud and AI Agent technologies from Tech Leads and engineers working in the industry.
* Explore solutions for optimizing cloud infrastructure architecture, information security, and cost management on AWS.
* Learn how to develop and deploy AI Agent applications, including Voice AI, Pentest Agents, and Agent Frameworks, in production environments.
* Network, exchange knowledge, and learn from the AWS Student Builder Group community and technology professionals.

### Key Highlights

#### Session 1: Hear, Think, Speak - Building a Vietnamese Voice-AI Contact Center on AWS

* **Voice AI Architecture:** Explored an approach to optimizing communication and processing pipelines to reduce call response latency to approximately 1.8 seconds, enabling smoother and more natural voice interactions.
* **Live Demonstration:** Observed a Vietnamese-language AI system conducting automated preliminary interviews for a Cloud Engineer position, demonstrating flexible and interactive responses.

#### Session 2: AWS Resource Access Manager (RAM)

* **Secure Resource Sharing:** Learned how resources can be shared across independent AWS accounts within the same AWS Organization to optimize costs and support centralized network management.
* **Multi-layer Access Management:** Explored how IAM policies and Service Control Policies (SCPs) work together to establish permission boundaries and prevent unauthorized privilege escalation.

#### Session 3: AWS Pentest with AWS Continuum / Security Agent

* **Early Infrastructure Security Assessment:** Explored integrating automated Infrastructure as Code (IaC) security checks for Terraform into GitLab or GitHub pull request workflows to identify configuration vulnerabilities before merging.
* **Automated Penetration Testing with Security Agents:** Learned about using Security Agents to simulate real user interactions and conduct automated penetration testing in SIT/UAT environments before production deployment.

#### Session 4: Amazon Bedrock AgentCore

* **Agent Runtime:** Learned about an approach to optimizing operational costs by running MicroVM-based agent workloads on EC2 Spot infrastructure.
* **Layered Memory Architecture:** Explored the distinction between short-term memory, synchronized within a session, and long-term memory, processed asynchronously, to help AI Agents maintain relevant user context.

#### Session 5: Kiro Crew - AI Agent 24/7 Review Code & System Monitoring

* **Task Automation:** Explored the development of AI Agents operating continuously to assist with code reviews and system health monitoring.
* **Flexible Artifact Generation:** Learned how Agents can automatically collect task-related data and visualize information through charts directly within a chat interface.
* **Context Window & Token Management:** Explored the *Auto Compact* mechanism for automatically compressing context when usage reaches approximately 70–90% of the available context window, along with *Break Down Context* features for examining token consumption across components.
* **Security & Memory Management:** Learned about implementing Guardrails to prevent AI Agents from executing dangerous commands, such as deleting infrastructure or exposing secrets and credentials, while managing outdated memory to control operational costs.

### Key Takeaways

#### Design Thinking & Architecture

* **Latency Management:** Gained practical insights into balancing AI model accuracy and real-time response speed in Voice AI applications.
* **Shift-Left Security:** Recognized the importance of integrating security assessments, including IaC reviews and automated penetration testing, early in CI/CD pipelines rather than waiting until production deployment.
* **AI Agent Lifecycle Management:** Understood the importance of managing memory, context windows, and resource costs, including EC2 Spot usage and token consumption, when operating AI Agents in production.

#### Infrastructure Engineering & Security

* **Privilege Boundaries:** Learned how IAM policies and SCPs can complement resource-sharing configurations involving AWS RAM to support the principle of least privilege in enterprise environments.
* **Generative AI Security:** Explored the use of Guardrails to control AI Agent behavior and reduce the risk of destructive infrastructure operations or sensitive data exposure.

### Application to Work

* **Integrating Security Scanning into CI/CD:** Research ways to incorporate IaC security checks, including Terraform reviews, into GitHub or GitLab pull request workflows for academic exercises or personal projects.
* **Applying Context & Memory Management Principles:** Explore context compression and layered memory approaches when developing chatbot applications or integrating LLM APIs.
* **Practicing AWS Access Management:** Study AWS Organizations, AWS RAM, and SCP configurations to strengthen my understanding of cloud security architecture.
* **Networking & Continuous Learning:** Continue exchanging knowledge with experienced engineers and actively participating in technology community activities.
